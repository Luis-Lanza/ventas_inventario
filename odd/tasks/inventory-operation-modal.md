## Product decisions and boundaries
- Select product directly into one modal over the still-mounted listing. Match `docs/design/velay-v1/inventario-entrada.png` and `inventario-conteo.png`: product summary, two operation cards, conditional fields, projected balance and footer actions.
- Closing discards draft immediately, without confirmation. Pending persistence cannot be dismissed or submitted twice. `Nueva operación` returns to browsing as the existing reset action.
- Success only after the actual persisted response: close to listing and use existing action notification. Preserve query/category/stock filter/page/view/results. Failure retains form/errors and retry identity; preserve existing password-clearing behavior.
- Keep loaded alerts on draft reset rather than exposing false empty status. Do not add gratuitous refresh; retain existing success refresh/cue orchestration.
- Capture actual selection button geometry; expand/contract frame without scaling text. Smooth entry/count content transition, reduced-motion bypass, bounded fallback, cleanup and eligible focus return (search fallback when opener is unavailable).
- Preserve existing validation, optional prices, count authorization and idempotency payloads. No new IPC, backend, schema, history or notification system.
- Sales/CheckoutDialog remain unchanged. Shared confirmation/motion options must be additive and preserve defaults; Inventory must not pretend to be Sales markup.
- Bounded native body scroll, reachable heading/footer, modal focus containment and background lock. Static/mock structural checks are not native visual acceptance.
